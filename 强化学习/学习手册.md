# 三天强化学习实验室

这是从模仿学习进入强化学习的源码学习项目。主任务 Pendulum-v1：观测为 cosθ、sinθ、角速度，输出 [-2,2] 力矩。回报越大越好，负回报不表示实现错误。

以下参数依次接在前缀后；输出和数据参数请使用绝对路径：

1. `train --algo ppo --steps 5000 --out <实验目录>`，再扩大到300000步。
2. `train --algo sac --steps 150000 --out <实验目录>`。 
3. `collect --algo sac --model <SAC模型.zip> --steps 20000 --data <数据.npz> --out <实验目录>`；不传 model 时采集随机策略。
4. `train --algo bc --data <数据.npz> --steps 20000 --out <实验目录>`。
5. `train --algo iql --data <数据.npz> --steps 50000 --out <实验目录>`。
6. `evaluate --algo iql --model <模型.pt> --out <评估目录>`。在线算法传 zip。
7. `plot --out <离线训练目录>`，输出 actor loss 图。

## 第一天：PPO

先读 cleanrl 中 ppo_continuous_action.py 的 Agent，再看 rollout 收集、GAE、ratio、clipped policy loss、value loss。画出 observation→Actor→action→环境→reward→GAE→更新的数据流。

V(s) 预测从状态出发的折扣回报；Q(s,a) 还指定第一步动作；A=Q−V 衡量动作相对平均水平的好坏。PPO 用新旧策略概率比乘优势，并裁剪更新激励；裁剪不是安全保证。旧 rollout 不能无限复用。

实验：随机策略与 PPO 使用同样20个评估种子。观察回报、entropy、KL、clip fraction；不能仅凭 loss 下降判断学会。

## 第二天：SAC

读 cleanrl 中 sac_continuous_action.py 的 Actor、SoftQNetwork、经验池、target_q、actor_loss、alpha_loss。SAC 用经验池重复使用旧策略数据，属于 off-policy；训练仍持续采样，因此通常属于在线强化学习。

Q target = r + γ(1−terminated)[min(Q1_target,Q2_target)−α logπ]。双Q缓解高估，目标网络缓慢跟随，熵鼓励探索。阅读 tanh 后概率密度修正，不能漏掉变量变换。

采集随机、中途、最终策略各20000条。先评估行为质量，再为数据命名；训练完成不自动等于专家。保存原始 reward 和真正 next_observation。时间截断仍 bootstrap，真正终止不 bootstrap。

## 第三天：BC 与 IQL

先在同一数据上跑 BC，再对照 CORL 的 algorithms/offline/iql.py 阅读本项目离线分支。

IQL：V 使用 expectile 回归 L=|τ−1[δ<0]|δ²，δ=Q−V；τ=.7 更关注较好动作。Q 拟合 r+γV(next)。Actor 使用 exp(β(Q−V)) 加权 BC，权重截断100。β=3，软更新率 .005。本教学入口使用确定性 actor 变体，不声称逐项复现论文 benchmark。

固定数据不会随策略改进而补充覆盖：数据外动作的Q可能虚高。普通SAC的Actor会主动利用Q高估；IQL价值学习主要查询数据内动作，再通过加权BC提取策略。它仍可能受覆盖不足影响，不保证胜过BC。

## 应用迁移

驾驶中的感知特征对应观测，轨迹或控制对应动作。日志需要相邻观测、动作、奖励、终止语义；BC数据只有观测和动作时，不能直接当完整RL数据。具身示范同理。闭环偏移、奖励投机与离线覆盖都应单独评估；离线评估轨迹不可回流训练。

## IL → RL：逐轮真实更新实验（新版）

启动 `/home/yimu/Desktop/leetcode/强化学习/启动教学.sh` 后，在 `http://127.0.0.1:8765/` 刷新页面，点击“进入逐轮仿真实验”。不要用 file:// 打开真实实验界面；API需要本地教学服务。

建议顺序：

1. 选择BC、种子0、学习率0.003，创建实验。第0轮是未训练网络的确定性均值动作，并非随机动作基线。
2. 点击“更新1轮+仿真”。看动作监督误差、链式梯度、Adam更新、真实200步回放。
3. 切换PPO创建新实验，对照“教师动作标签”和“自采动作的GAE优势”。
4. 切换SAC看Q如何给Actor传梯度；再看IQL如何给BC误差加优势权重。
5. 用“上一轮/第0轮”同步比较，拖动时间轴查看同一时刻的角度、速度、力矩和累计回报。
6. 选“连续观察5轮”，每轮更新、仿真、回放完才继续下一轮；“本轮后暂停”不会丢弃正在完成的一轮。

一轮定义：各相关优化器各step一次，然后独立评估一次。PPO做一次联合Actor/Critic step；SAC做Q、Actor、温度各一次；IQL做V、Q、Actor各一次；BC只做Actor一次。这个教学PPO每轮更新一个完整批次，同一rollout复用4轮：第1步ratio=1，后续步可能触发clipping；用满4轮后重新采样。标准PPO通常在rollout上进行多轮minibatch更新。

小网络、默认较高学习率是为了便于观察，不是最优超参数。一次固定初态下的回报可升可降；第一轮不保证明显改善。正式算法比较使用独立多初态、多种子评估。

离线BC/IQL初始化使用2048条启发式脚本控制器+30%随机动作数据，不称专家。初始化后冻结，评估轨迹不回流。SAC维护在线经验池；PPO每4轮采集256步，同一rollout进行4次全批更新，每次之后都独立仿真。
