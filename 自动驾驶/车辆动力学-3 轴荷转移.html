轴荷转移

加速、制动、转弯时，作用在质心（高度 h）上的惯性力会产生力矩，把垂向载荷从一侧车轮“搬”到另一侧。搬多少只取决于 m、a、h 和轴距/轮距

1静态轴荷

车辆静止在水平路面上时，对前、后轮接地点分别取力矩平衡：

$$F_{zf,0} = mg\,\frac{l_r}{L},\qquad F_{zr,0} = mg\,\frac{l_f}{L}$$

质心越靠前（$l_f$ 越小），前轴分到的载荷越多。前置发动机的轿车，前轴通常承担约 55%–60% 的重量。

2纵向载荷转移（加速 / 制动）

车辆以加速度 $a_x$ 运动时，在质心上加一个惯性力 $-m a_x$（达朗贝尔原理）。它的作用线比地面高 $h$，对接地点产生额外力矩，于是：

$$F_{zf} = mg\frac{l_r}{L} - \frac{m a_x h}{L},\qquad F_{zr} = mg\frac{l_f}{L} + \frac{m a_x h}{L},\qquad \Delta F_{z,x} = \frac{m\,a_x\,h}{L}$$
  • 制动（$a_x<0$）：载荷向前轴转移，车头下沉（点头）。前轮附着力增加，所以前制动器通常比后制动器大得多。
  • 加速（$a_x>0$）：载荷向后轴转移，车头抬起。后驱车起步更容易，前驱车大油门起步容易打滑。
  • 理想的前后制动力分配应与动态轴荷成正比（I 曲线）：$\dfrac{F_{bf}}{F_{br}} = \dfrac{l_r + z h}{l_f - z h}$，其中 $z = -a_x/g$ 为制动强度。

3横向载荷转移（转弯）

转弯时，惯性力 $-m a_y$ 把载荷从内侧车轮转移到外侧。把车身看成刚体（忽略侧倾中心）时，左右两侧之间转移的总载荷为：

$$\Delta F_{z,y} = \frac{m\,a_y\,h}{B}$$

这部分转移在前、后轴之间怎么分配，主要由前后侧倾刚度（弹簧、防倾杆）决定。设前轴承担比例为 $\phi$：

$$\Delta F_{z,f} = \phi\,\Delta F_{z,y},\qquad \Delta F_{z,r} = (1-\phi)\,\Delta F_{z,y}$$
进阶：考虑侧倾中心高度 $h_f, h_r$ 时，前轴转移量为 $\Delta F_{z,f} = \dfrac{m a_y}{B}\Big(\dfrac{K_{\phi f}}{K_{\phi f} + K_{\phi r}}\, h' + \dfrac{l_r}{L} h_f\Big)$，其中 $h'$ 是质心到侧倾轴的距离。本页相当于侧倾中心在地面（$h_f = h_r = 0$，$h' = h$）的情形。

4侧翻阈值

内侧车轮载荷减到 0 时，车辆开始侧翻。此时 $\Delta F_{z,y} = mg/2$，对应的侧向加速度为：

$$a_{y,\text{roll}} = \frac{B}{2h}\,g$$

$B/(2h)$ 叫静态稳定系数（SSF）。几何上看，就是重力和惯性力的合力作用线正好穿过外侧车轮的接地点（右侧后视图里的红色虚线）。

5载荷转移为什么会降低抓地力

轮胎的最大侧向力随载荷增大，但增长越来越慢（载荷敏感性，见第 2 页）。设 $F_{y,\max}(F_z)$ 是凹函数，那么：

$$F_{y,\max}(F_z + \Delta) + F_{y,\max}(F_z - \Delta) < 2F_{y,\max}(F_z)$$

外侧轮多得到的抓地力，弥补不了内侧轮失去的。所以哪根车轴分到的横向转移越多，哪根车轴的侧向附着损失就越大：

  • 前轴侧倾刚度大（$\phi$ 大，例如前防倾杆硬）→ 前轴先失去抓地 → 不足转向（推头）。
  • 后轴侧倾刚度大（$\phi$ 小）→ 后轴先失去抓地 → 过度转向（甩尾）。

调整防倾杆就是调整 $\phi$，这是改变车辆操控平衡最常用的手段。右侧“附着能力”表格里可以看到前后轴各自的损失。

6常见误区

误区：“弹簧越软，载荷转移越大。”
稳态下，总的转移量只取决于 $m, a, h, L, B$，和弹簧软硬无关（忽略侧倾带来的质心横移）。悬架只能改变前后分配和建立快慢。车身侧倾大，不等于载荷转移大。
误区：“车身下沉的一侧载荷才增加。”
即使悬架完全刚性、车身没有任何俯仰或侧倾，载荷转移也一样存在。它是力矩平衡的结果，不是悬架变形的结果。
