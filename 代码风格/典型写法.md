```python
dp = []
for i in range(n):

```

## 闭区间二分

nums 升序，返回任意一个目标值下标，不存在返回 -1。

```python
class Solution:
    def search(self, nums: list[int], target: int) -> int:
        left = 0
        right = len(nums) - 1

        while left <= right:
            mid = (left + right) // 2
            if nums[mid] == target:
                return mid
            elif nums[mid] > target:
                right = mid - 1
            else:
                left = mid + 1

        return -1
```

## 无重复字符滑动窗口

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        last_seen = {}
        left = 0
        max_len = 0

        for right in range(len(s)):
            current = s[right]
            if current in last_seen and last_seen[current] >= left:
                left = last_seen[current] + 1
            last_seen[current] = right
            max_len = max(max_len, right - left + 1)

        return max_len
```

last_seen 保存字符最近一次出现的位置；只有该位置仍在窗口内才移动 left，不需要逐个删除旧记录。

## 完整 DP 状态

非空矩形 grid，只能向右或向下，求左上角到右下角的最小路径和。

```python
def min_path(grid):
    dp = []
    for i in range(len(grid)):
        row = []
        for j in range(len(grid[0])):
            if i == 0 and j == 0:
                row.append(grid[i][j])
            elif i == 0:
                row.append(row[j - 1] + grid[i][j])
            elif j == 0:
                row.append(dp[i - 1][j] + grid[i][j])
            else:
                row.append(min(dp[i - 1][j], row[j - 1]) + grid[i][j])
        dp.append(row)

    return dp[-1][-1]
```

dp[i][j] 表示到达该格的最小路径和；当前行尚未加入 dp，所以左侧状态从 row 读取。

## 回溯

从 1 到 n 中选择 k 个数，题目保证 0 ≤ k ≤ n。

```python
class Solution:
    def combine(self, n: int, k: int) -> list[list[int]]:
        res = []
        path = []

        def back(start):
            if len(path) == k:
                res.append(path[:])
                return

            for i in range(start, n + 1):
                path.append(i)
                back(i + 1)
                path.pop()

        back(1)
        return res
```

start 避免重复选择和重复排列；`path[:]` 保存当前内容的副本。如果题目规模需要剪枝，再补充可解释的上界。

## 邻接表 BFS

graph 为已经构建的邻接表，start 为合法起点；求可到达的节点集合。

```python
from collections import deque

queue = deque([start])
seen = {start}

while queue:
    cur = queue.popleft()
    for num in graph[cur]:
        if num not in seen:
            seen.add(num)
            queue.append(num)
```

append 从右侧入队，popleft 从左侧出队。大规模稀疏图优先邻接表，小规模问题允许更直观的矩阵。

## ACM 输入示例

仅适用于“第一项 n，随后 n 个整数，输出元素和”的题目；其他题目按自己的格式解析。

```python
import sys

# sys.stdin = open('input.txt', 'r')

data = sys.stdin.read().split()
n = int(data[0])
nums = []
for i in range(n):
    nums.append(int(data[i + 1]))

print(sum(nums))
```

如果题目输入保证有 n，不必额外加入空输入分支。字符串中的空格有意义时不采用这个读取模板。
