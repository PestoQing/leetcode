# 踩坑记录

生成或修改演示页之前先读一遍。每条记的是：现象 → 原因 → 规避方法。新踩到的坑请追加在对应分类下。

## 动画与交互

### 点击按钮后动画永久停止
- **现象**：车辆动力学-1/4 切换「参考点」或点「典型场景」后，轨迹回放不动了。在无头浏览器里用 `el.click()` 测试却一切正常。
- **原因**：Chrome 在一帧的开头处理真实鼠标输入，处理完才跑 rAF 回调。点击处理函数里记的 `t0 = performance.now()` 会**晚于**同一帧 rAF 回调拿到的时间戳 `now`，于是 `now - t0 < 0`，`Math.floor(t / dt)` 得到负下标，`pts[-1]` 是 `undefined`，读属性抛错。而 `requestAnimationFrame(loop)` 写在绘制之后，抛错后不会再排下一帧，动画就此停止。
- **规避**：
  - 时间差一律写成 `Math.max(0, now - t0)`，引擎的 `AV.animate` 也已经这样处理。
  - 自写 rAF 循环时，在回调**第一行**就 `requestAnimationFrame(loop)`，让单帧出错不至于停掉整个动画。
  - 用 `scripts/check_click.cjs` 做真实点击回归，它走 CDP `Input.dispatchMouseEvent`。`el.click()` 和 `Runtime.evaluate` 都绕过了"帧开头处理输入"的时序，复现不了这个问题。

### 预设 / 典型场景按钮点了不高亮
- **现象**：点击「停车场掉头」「babad」等预设按钮后，看不出当前选的是哪个。
- **原因**：预设按钮只负责填值并重算，没有维护选中状态。
- **规避**：记下每个预设的完整取值，当前参数和哪个预设一致就给哪个按钮加 `.on`；同值时优先刚点的那个；手动改输入或拖滑块偏离后自动取消；「重置」也算一个预设。模板引擎（`markPreset`）和车辆动力学页的 `UI.presets` 都已经实现。`check_click.cjs` 会检查点过的 `button.preset` / `.seg button` 是否带 `.on`。

## 公式排版（MathML）

### 排版后每一步都在闪、重绘
- **原因**：`$…$` 被转换成 MathML 之后，`node.innerHTML` 已经不等于源字符串，`if (node.innerHTML !== html)` 每次都成立。
- **规避**：写入用 `AV.setHTML(node, html)` 或 `AV.setText`，它们按原始字符串比较。`patch_tex.py` 会自动改写旧页面里的这种比较写法。

### 自检误报「文字重叠」
- **原因**：上下标、ᾱ 的上横线等字形框会互相叠住，逐个文字节点检查就会报重叠。
- **规避**：自检里把整个 `<math>` 当成一个文字块（`textRects` 中的 `seenMath`），`patch_tex.py` 已经同步。

### ᾱ 的上横线不显示；普通括号被分式撑高
- **原因**：Edge 的 MathML 里，`<mover>` 用 U+00AF / U+203E 作重音时不绘制；`<mo>(</mo>` 默认可伸缩，会跟着同一行里的分式变高。
- **规避**：`\bar` 用 U+2015；不在 `\left…\right` 里的括号输出 `stretchy="false"`。这两点 `tex_engine.js` 都已处理。

### 行内分式太小，或上下两行公式相互叠住
- **规避**：`.formula` 里的 `math` 用 `math-style: normal`，按独立公式的字号排版。一行里同时有大求和和大分式时，其中一个改用斜杠写法，例如 `(a - b) / \sqrt{c}`。统计卡标题、输入标签里的公式字号设为 1em，否则会把卡片撑高，导致 100% 缩放时左侧出现滚动。

### TeX 反斜杠丢失
- **现象**：`\nabla` 变成换行加 `abla`，`\frac` 变成 `rac`。
- **原因**：一是 JS 字符串里的 `'\n'`、`'\f'` 是转义字符；二是 Git Bash 的 heredoc（`<<'EOF'`）在这台机器上会把 `\\` 吞成 `\`。
- **规避**：JS 字符串里一律写 `\\`。含反斜杠的脚本或补丁用 Write 工具写成文件再执行，不要用 heredoc，也不要用 `python -c`。

## 布局与自检
- `check.py` 只有在 80% 和 100% 两种缩放下**都是** OK 才算通过。100% 缩放时左侧多出几个像素的滚动，通常是统计卡或副标题被撑高了（公式、换行）。
- dp 表、矩阵这类二维结构的格子尺寸要按画布**高度**来算，并限制输入规模（例如最长回文子串最多 10 个字符），表头行列用固定的小尺寸。
- 只要页面有按钮（预设、分段切换、播放类按钮），除了 `check.py`，还要跑 `node scripts/check_click.cjs <页面.html> [额外按钮选择器]`。

### 队列文字被内部滚动截断后，自检仍报告重叠
- 现象：长文本节点在定高 overflow:auto 容器中，范围测量可能涵盖裁切区域外的文字。
- 处理：队列与距离记录只展示明确标注的有限条目，并显示剩余数量；避免让裁切的长文本延伸到下一个面板。栅格画布明确设置响应高度，防止默认高度过小。
