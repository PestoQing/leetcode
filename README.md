# 市场脉搏行情看板

本地网页展示纳斯达克100、恒生科技、上证指数、创业板指数、魔门塔（06880.HK）和宇树科技（688836.SH）的最新行情、成交额、PE、换手率及可拖动缩放的图表。行情卡片约每 30 秒自动刷新。

## 启动

在本目录运行：

```bash
python3 server.py
```

打开终端显示的 `http://127.0.0.1:8765`。关闭终端或按 `Ctrl+C` 停止。

页面需要联网获取行情数据。日、周、月、季、年周期显示 K 线；单日显示连续折线。图表可用鼠标拖动横向浏览，滚轮缩放；“最新”回到最新数据。

K 线和实时报价由腾讯行情接口提供，PE 与部分成交额字段由东方财富补充。指数 PE 和换手率显示为不适用；行情源未提供的字段会明确标注。报价延迟和字段可用性取决于数据源。
